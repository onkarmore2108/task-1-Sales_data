# task-1-Sales_data
this task is to clean and preprocess a raw sales dataset and prepare it for data analysis.

# Data Cleaning Steps
Loaded the sales dataset using Pandas.
Checked for missing values.
Filled missing numerical values using the median.
Filled missing text values with "Unknown".
Identified and removed duplicate records.
Standardized column names by converting them to lowercase and replacing spaces with underscores.
Removed extra spaces from text values.
Converted the order date column into datetime format.
Checked and verified the data types.
Saved the final cleaned dataset as cleaned_sales_data.csv.
